# Functional audit and module readiness — 2026-10-26

Baseline: 11ccebd. Inspected frontend routes/forms, platform and Stage 2/3 services, migrations, scoped data access, provider boundary, API/worker startup and executable tests. Used a new loopback server on port 4002 with its own .tmp/product-audit/browser.db, three public synthetic identities and no external AI access. Existing databases and demos were preserved. Browser rendering covers all 26 workspace sections on mobile and desktop (Transactions added to the desktop matrix at final review). Rendering is not proof of every mutation; backend integration journeys supply separate persistence/authorization evidence.

| Module | Observed / executed evidence | Readiness and gaps |
| --- | --- | --- |
| Authentication | Signup/verify, sign-in, recovery, one-time reset, session revocation/sign-out HTTP tests; connected browser sign-in and refresh | Functional development/sandbox. Production signup/recovery gated by email delivery; no real email test. |
| Organizations/team | Two unrelated organizations; invite/viewer denial, verified operator gates and environment tests | Functional scoped backend/UI. General team lifecycle is not a full identity-provider integration. |
| Customers | Browser create, refresh, mobile edit/clear email/refresh; search/pagination and correction/history tests | Functional create/read/edit/search. Archive/delete and advanced CRM filters not implemented. |
| Orders | Browser itemized order→issue→linked invoice; totals, fulfillment/protected guards, cancellation rules tested | Functional permitted states. Full editing of issued financial history is intentionally restricted. |
| Invoices | Browser create/issue/paid result; exact partial/final receipt journey and source-linked order update; print view inspected | Functional draft/issue/allocation/eligible void flows. PDF is browser printing, not a server-generated file. Formal credit notes, external sending and eTIMS absent. |
| Payments/checkout | Browser delayed→pending→success; HTTP failures, expiry, duplicate/concurrent/out-of-order events, signed callback forgery/age and live denial | Functional sandbox. No live M-Pesa/bank collection or verified settlement. Missing callback remains pending, not assumed paid. |
| Reconciliation | Exact KSh 2,500 invoice, KSh 1,500 receipt, KSh 1,000 final receipt; allocation sum/count, replay, order/report/CSV checks | Functional supported single-document allocations/review. Arbitrary split/reallocation and automatic reversal settlement remain incomplete. |

| Assistant | All four tools return bounded source evidence; fixture provider consent, missing config, error, minimized input, logs, tenant denial, quota-before-execution tests | Functional retrieval/security boundary. No external paid model called; real-provider answer quality/network availability unverified. Read-only, no financial execution. |
| Automation/notifications | Schedule dedupe, pause/preferences, permission recheck, durable run/notice, failed-workspace isolation and second-tick no-duplicate test | Functional single-process in-app reminders. | Sharing/network | Recipient/purpose/audience/nonce binding, one-time use, revoke/replay/expiry, counterparty confirmation/rejection/revocation tests | Functional sandbox. | Blockchain | Isolated local EVM deploy/transaction/root/inclusion, wrong/tampered proof and independent verifier | Genuine local-chain functional checks. No configured public testnet/mainnet deployment; production publication disabled. |
| Developer platform | Scoped key storage/revoke, role/environment denial, actual invoice example/OpenAPI, webhook signature/retry/dead-letter/replay tests | Functional sandbox/API foundation. Full SDK/field-level contract and live external receiver qualification open. |
| Engineering/internal ops | Owner browser denied; verified issuer/operator path reviewed separately; private-route tests | Existing allowlist retained. Live issue sync/autonomous execution absent. |
| Legacy platform | Existing consent/ledger/import/Orbit/link/privacy regression suites retained | No implicit migration/ownership or API replacement. Legacy amount semantics stay separate. |

No module is declared generally production ready by this audit. Local functional success does not establish partner authorization, external security/regulatory review, distributed operation, load capacity or accessibility conformance. Unavailable production capabilities remain visibly gated. No destructive migration or production setting was changed.
