# Original editorial illustration system
Seventeen original editable SVG scenes live in website/public/media/editorial, generated by scripts/generate-illustrations.js: business, payments, reconciliation, invoicing, cashflow, protected-payments, integrations, automation, developers and education. Combined source size is about 28 KB. No third-party illustration is copied or embedded. Run node scripts/generate-illustrations.js to reproduce them.

Shared art direction: restrained orange story accents, charcoal outlines, green/olive accents, warm skin/cream fills, editorial adult figures, expressive business gestures and negative space. Scenes communicate Kenyan/African business operations without using a real person's likeness. Original vector geometry remains editable. NVIDIA influenced layout discipline; the requested Robinhood reference influenced only the general editorial category, not traced artwork.

website/src/editorial.ts defines typed media descriptors and route mappings. Existing Media/FeatureSection boundaries support swapping SVG/screenshot/video without page reconstruction. Keep hero composition, strong typography, whitespace, existing brand CTAs and real UI previews for product detail. Illustration does not enter dense reporting tables. Developers retain practical interface/code content. All images need contextual alt text and explicit dimensions/aspect ratio.

EducationalFlow.tsx illustrates four conceptual purchase stages with keyboard-operable tabs; it never pretends to execute a payment. CSS motion is restrained and disabled by prefers-reduced-motion. Public imagery loads lazily away from the hero; no video library or heavy animation dependency was added. Validate desktop/mobile sizing, alt text, keyboard focus and overflow after media replacement. Visual assets are not evidence of operational payment partnerships.
