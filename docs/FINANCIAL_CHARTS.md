# Financial chart refinement

Historical controls 7D, 30D, 90D, YTD, 1Y and ALL stay selectable with empty or short history. Calendar boundaries filter actual loaded dates, not record indices. Up to one year is requested for the Business activity overview; ALL means all loaded records. Reports respect explicit filters. Empty compact charts omit meaningless readout dashes and repeated legends. Existing keyboard/pointer/exact-table features remain.

Personal activity uses recorded income/expense/net points. Business provider payment activity remains explicitly test data in sandbox. Forecast horizons retain their own availability constraints. No synthetic points, currency mixing, profit implication or mainnet activation. All six historical controls were clicked in the local browser and each reflected its pressed state.
