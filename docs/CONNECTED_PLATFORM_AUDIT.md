# Connected platform capability audit

Reviewed against release f0dccb2, Milestone 3 owner request. This matrix records the pre-change implementation; final outcomes belong in the release report. Existing payment infrastructure remains authoritative. No new language, microservice, workflow engine or on-chain financial ledger is required.

| Product | Existing backend / persistence / UI | Security and dependencies | Readiness and missing work | Planned changes / validation |
| --- | --- | --- | --- | --- |
| Financial Intelligence | Shared Milestone 2 snapshot, exact money, aging, sparse charts, explainable forecast | Workspace/currency/date scope; optional Intelligence entitlement | Internal implemented; configurable alerts, metric metadata and forecast evaluation need improvement | Source metadata, configurable evidence-backed alerts, scenario tests; reuse snapshot |
| AI Assistant | Fixed read tools, Responses adapter, request-level consent, global/user/workspace reservations, token audit; form UI with ephemeral history | Verified human identity, optional service, no SQL/write tools, bounded input/output, store:false | Real output previously credit-blocked; no persistent private conversations/citations/feedback; Personal/Developer eligibility limited | Encrypted actor-private conversations, deterministic citations, messaging UI, feedback, usage visibility; adversarial/provider tests; reuse approved key |
| Automations | Templates, typed conditions, PostgreSQL/SQLite durable runs, retries/dead letter, notifications, worker; list/create/pause | Execution-time creator membership and service check; notifications only; single instance | No edit/version history; delays/timezones/cancellation/diagnostics incomplete; old overdue arithmetic ignores credits | Immutable versions, bound queued config, bounded retry/cancel, timezone and delay; recheck receivables before reminders |
| Connect | Typed sandbox accounting/courier/store registry, explicit import, retry/disconnect, durable objects | Admin scope and service; imports remain synthetic | Genuine bank/accounting OAuth programs not configured; CSV exists outside connector view | Authorized file ingestion with canonical lineage/checkpoints/conflicts; honest registry health and permission UI; no unsupported external credential collection |

| Business Verification | Encrypted bounded document upload, manual operator review, audit, renewal via existing identity reviews | Separate verified operator allowlist; sandbox; MIME/signature checks | No registry authority, malware service or automatic document verification | Explicit scan/assurance disclosure and workflow visibility; preserve private review boundaries |
| Passport | Private profile, evidence, credential wallet, material-change invalidation | Human admin; controlled grants, current membership; existing encryption | Functional internal sandbox; missing cross-product assessment summary | Improve independent dimensions and routes; retain private evidence and whole-credential sharing limitations |
| Credentials | JOSE ES256 VC2 profile, authorized issuer registry, holder request, signed status lists, rotation/compromise, export | Private encrypted keys, source hashes, distinct issuer/holder/verifier, bounded verification | Real local signatures; no OpenID wallet conformance or institutional authorization | Preserve standards profile; extend lifecycle regression and clear external readiness |
| Trust Network | Explicit bilateral relationships, correction/dispute history, evidence coverage | No implied invoice relationship; no public financial sharing | Coverage is not trustworthiness; independent assessment dimensions missing | Private evidence-based dimension report and corrections navigation, no composite credit/procurement decision |
| Blockchain | Randomized commitments, OpenZeppelin Merkle batching, access-controlled no-funds contract, independent verifier | Local chain only by default; private sources off-chain; production gated | Local verified; no approved public network/RPC/mainnet or external audit | Preserve contract, strengthen operational disclosure and regression; no new production contract |
| Marketplace / APIs | Exact capability/service maps, reservations and idempotent usage, generated API contracts | Independent services; unknown routes fail closed | New commands need exact mappings and schema metadata | Add explicit mappings/contracts, independent activation and no-double-meter tests |

Execution order: shared intelligence and private conversation foundation; workflow reliability; lineage/Connect; private trust assessment and lifecycle integration; full regression and responsive QA; guarded additive development migration; backend then Cloudflare release. External provider/billing/institutional authority remains separately gated. Milestone 4 remains on hold.

Standards reviewed: OWASP LLM01, W3C VC2 and Bitstring Status List recommendations, OpenID4VCI/VP final specifications. Existing managed JOSE presentation is not claimed as full OpenID conformance. OpenAI Responses documentation confirms the current bounded request approach; no model migration is required.
