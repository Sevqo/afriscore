# Authenticated application design system

The existing shared theme remains canonical. system.css scopes operational density to Business, Personal, Developer and account entry shells. Public editorial pages and sidebar structure are preserved. Mobile heading 26px, desktop 30px; sections 19–21px; body 14px; form text 16px and minimum 44px controls. Metrics use tabular numbers, two mobile columns and four desktop columns. Date fields use border-box sizing and min-width:0. No new font or parallel token system.
