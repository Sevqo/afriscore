| Product | Unique task / outcome | Primary teaching structure |
| --- | --- | --- |
| Business | Operate customer/order/invoice/team records | Real workspace preview and working-day walkthrough |

| Cash Flow | Explain recorded inflows less outflows | Inspectable financial chart with explicit source coverage |
| Intelligence | Decide under collection uncertainty | Evidence → assumptions → forecast → possible response |
| Automation | Execute defined administrative follow-up | Trigger/condition/action/run history, failure boundaries |
| Connect | Retrieve authorized external records | Source-to-normalization diagram and connector status table |
| Data | Validate/standardize and preserve provenance | Same system comparison focused on structured output |
| Passport | Share selected business proof with a customer | Supplier/customer scenario and minimal disclosure |
| Business Verification | Review specific identity claims | Evidence review checklist with assurance distinctions |
| Credentials | Check an issuer's signed claim | Issuer/holder/verifier roles and independent checks |
| Trust Network | Corroborate commercial relationships | Selectable relationship states, no endorsement inference |
| Blockchain | Independently inspect an anchored commitment | Commitment/batch/root/inclusion, developer disclosure |
| Protected Payments | Coordinate delivery and reviewed outcomes | Buyer/seller comparison and sandbox state boundaries |
| Privacy | Limit what a named recipient receives | Selective claim preview and access limitations |
