WHY IT MATTERS

Move from records
to decisions.

Each stage is an isolated queue with its own worker, retry policy and idempotency key. The API returns a workflow id immediately; the console watches the state machine walk from PENDING to READY.

  • ingestion — consent verified, raw text extracted
  • normalization — parse, dedupe by receipt, insert
  • ledger — hash-chain append, once per event
  • scoring — health, DSO and decision card
